Box Shadow and Text Shadow properties in CSS

Box Shadow

Box shadow is a CSS property that adds a shadow effect around an element's frame. It allows you to define the shadow's horizontal offset, vertical offset, blur radius, spread radius, and color.

Syntax

        box-shadow:  [horizontal offset-x] [vertical offset-y] [blur-radius] [spread-radius] [color];
